# **Нарушения принципов SOLID**

### 1.1. Принцип единственной ответственности (SRP)

Нарушение: класс Main содержит слишком много ответственностей

main()

Класс отвечает за:
* парсинг аргументов командной строки
* чтение конфигурации
* создание объектов
* логику выполнения операций
* вывод результатов

Исправление: выделить отдельные классы для каждой ответственности

### 1.2. Принцип открытости/закрытости (OCP)

Нарушение: отсутствие абстракций для операций

main() (строки с условиями if-else для операций)

Описание: для добавления новой операции необходимо изменять существующий код

Исправление: создать интерфейс Operation и реализовать конкретные операции

### 1.3. Принцип подстановки Барбары Лисков (LSP)

Нарушение: отсутствие четкой иерархии и контрактов

Весь проект

Описание: нет базовых классов/интерфейсов, которые могли бы быть заменены подтипами

Исправление: создать абстрактные классы/интерфейсы с четкими контрактами

### 1.4. Принцип разделения интерфейсов (ISP)

Нарушение: отсутствие специализированных интерфейсов

Весь проект

Описание: нет интерфейсов, клиенты вынуждены зависеть от методов, которые не используют

Исправление: создать специализированные интерфейсы для разных типов операций

### 1.5. Принцип инверсии зависимостей (DIP)

Нарушение: прямые зависимости от конкретных реализаций

Класс Main напрямую создает и использует конкретные объекты

Исправление: внедрить зависимости через интерфейсы и использовать Dependency Injection
